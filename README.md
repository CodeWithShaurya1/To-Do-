# JavaScript To-Do App

A simple command-line style To-Do application created using **JavaScript**.

## About

This is a basic JavaScript project that allows the user to manage a list of tasks.

The project was created to practice fundamental JavaScript concepts such as:

* Arrays
* Variables
* Loops
* Conditional statements
* `prompt()`
* `console.log()`
* Array methods such as `push()`, `indexOf()`, and `splice()`

## Features

The application supports:

* **Add** — Add a new task to the To-Do list.
* **List** — Display all current tasks.
* **Delete** — Remove a task from the list.
* **Quit** — Exit the application.

## How to Use

Run the JavaScript file in a browser environment that supports `prompt()`.

Enter one of the following commands when prompted:

```text
add
list
delete
quit
```

### Example

```text
add
Enter the task to add: Study JavaScript

list
Your all todo tasks are:
["Study JavaScript"]

delete
Enter the task you want to remove: Study JavaScript
Item deleted successfully

quit
Game End
```
